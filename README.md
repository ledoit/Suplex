# SUPLEX

Local 2-player physics wrestling inspired by *Get On Top*.

**Stack:** Zig 0.17 → `wasm32-freestanding` physics, vanilla canvas host.

**Live:** https://suplex.menhir-holdings.com

## Run

```bash
bun run build
bun run serve
```

http://localhost:4173

## Controls

| Fighter | Keys |
|---------|------|
| Cyan (P1) | `W A S D` |
| Coral (P2) | Arrow keys |
| Rematch | `R` |

Hold their **head** on the mat (~0.3s) while you’re on top to score. First to **11**.
